# Part 7: Android Foundations

Build your first Android apps with Kotlin and Jetpack Compose.

## What You'll Learn

- Creating and running an app in Android Studio
- The `Activity` lifecycle and configuration changes
- Android UI with the View system and Jetpack Compose
- Kotlin idioms for Android and platform-type null safety
- Using coroutines and `Flow` with lifecycle-aware scopes
