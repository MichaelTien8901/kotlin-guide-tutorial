# Part 7: Android Foundations

Build your first Android apps with Kotlin and Jetpack Compose.

## What You'll Learn

- Creating and running an app in Android Studio
- The `Activity` lifecycle and configuration changes
- Android UI with the View system and Jetpack Compose
- Kotlin idioms for Android and platform-type null safety
- Using coroutines and `Flow` with lifecycle-aware scopes

## Chapters

| Chapter | Description |
|---------|-------------|
| Android Setup | Android Studio, project anatomy, run on emulator |
| Lifecycle | `Activity` lifecycle, config changes, state |
| UI & Compose Intro | Views overview + Jetpack Compose basics |
| Android Kotlin Idioms | Platform types, null safety, idioms |
| Coroutines on Android | `viewModelScope`, lifecycle-aware `Flow` |

{: .important }
Android chapters require Android Studio and an emulator or device. Each chapter
notes its hardware/emulator requirements.
