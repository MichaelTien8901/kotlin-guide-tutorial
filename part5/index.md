# Part 5: Functional & Advanced

Embrace Kotlin's functional style and its more advanced language features.

## What You'll Learn

- Lambdas, higher-order functions, function references, and `inline`
- Scope functions: `let`, `run`, `with`, `apply`, `also`
- Class delegation and delegated properties
- Operator overloading and conventions
- Building type-safe DSLs
- Exceptions, annotations, and reflection basics
