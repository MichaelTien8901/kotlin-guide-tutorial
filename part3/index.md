# Part 3: OOP & Functions

Model your domain with Kotlin's object-oriented and function features.

## What You'll Learn

- Classes, constructors, properties, and visibility
- Inheritance, interfaces, and abstract classes
- `data`, `enum`, and `sealed` classes with exhaustive `when`
- Objects, companion objects, and singletons
- Extension functions and advanced function features

## Chapters

| Chapter | Description |
|---------|-------------|
| Classes | Constructors, properties, accessors, `lazy` |
| Visibility | Modifiers, packages, imports |
| Inheritance & Interfaces | `open`/override, abstract, interfaces |
| Data, Enum & Sealed | `data`/`enum`/`sealed` + exhaustive `when` |
| Objects | `object`, `companion object`, singletons |
| Extensions | Extension functions, `infix`, `vararg` |
